# 웹 결과물 점검 체크리스트

## 데이터·계산 (가장 중요)
- 화면에 나온 핵심 숫자 2~3개를 별도 스크립트나 손계산으로 원본 데이터와 대조
- 필터·정렬·집계 결과가 원본과 일치하는지
- 단위, 소수점, 날짜·시간대 표시

## 입력
- 빈 값, 공백만, 아주 긴 값, 한글·특수문자, 숫자 자리에 문자
- 같은 요청 두 번(중복 제출)
- `<script>alert(1)</script>` 입력 시 그대로 실행되지 않는지

## 상태
- 데이터가 0건일 때 화면
- 오류가 났을 때 사용자에게 보이는 메시지
- 새로고침 후 유지돼야 하는 값이 유지되는지

## 로그인·권한 (화면에서 숨기는 것과 서버에서 막는 것은 다르다. API를 직접 호출해서 확인)
- 로그인하지 않고 보호된 API 호출 → 401
- 일반 사용자가 관리자 API 호출 → 403
- 일반 사용자가 다른 사용자 ID로 조회 → 403 또는 404
- 일반 사용자 응답에 다른 사람의 이름·개인 정보가 섞여 있지 않은지
- 로그아웃 후 이전 세션으로 다시 호출 → 거부
- 확인 방법: `curl -i -b "세션쿠키" http://localhost:포트/api/...`

## 보안·운영
- 프론트엔드 코드나 응답에 비밀정보·내부 경로 노출 여부
- 서버 0.0.0.0 바인딩, 포트 확인
